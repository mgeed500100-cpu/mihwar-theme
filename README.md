# محور — Mihwar

ثيم Twilight لقطع غيار السيارات والإكسسوارات والعناية، مبني على قالب Raed الرسمي من سلة.

## ما يميّز النسخة الأولى

- واجهة سينمائية داكنة مع لون المتجر الأساسي كلون إبراز.
- بحث مباشر عن المنتج ورقم القطعة عبر بحث سلة.
- محدد سيارة يربط الشركة/الموديل/السنة بنتائج يجهزها التاجر.
- شبكة تصنيفات Bento قابلة لإعادة الترتيب من محرر الثيم.
- منتجات مختارة وعلامات موثوقة وحركات خفيفة تراعي `prefers-reduced-motion`.
- دعم العربية والإنجليزية وتصميم متجاوب.

## تشغيل محلي

```bash
pnpm install
pnpm development
```

للمعاينة داخل متجر تجريبي استخدم Salla CLI وفق دليل Twilight، ثم اربط مكونات الصفحة الرئيسية من محرر الثيم.

## ملاحظة التوافق

محدد السيارة في هذه النسخة يعتمد على روابط نتائج أو تصنيفات يضبطها التاجر. المطابقة الدقيقة برقم الهيكل VIN تحتاج تطبيقاً وقاعدة بيانات مستقلة ويمكن إضافتها كمرحلة لاحقة.
